Import game files into this browser

One-time step. Choose your extracted Mario Kart Wii disc (the folder with files and sys inside). The files are copied into this site's private storage on this device. Files you already copied are skipped, so you can run it again safely.

This device

    Choose your game files

    1. On iPad: in the Files app, long-press the extracted disc folder and tap Compress. Then choose the .zip here.
    2. A .tar of the folder works too, and on a computer you can pick the folder directly.
